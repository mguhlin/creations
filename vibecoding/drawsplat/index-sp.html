About DrawSplat

DrawSplat is a free K-16 interactive whiteboard for classrooms and small-group collaboration. Draw, place sticky notes, attach audio, organize panels, and share boards via Google Drive.

Vibe-coded by Miguel Guhlin. For more education-technology writing, visit the TCEA blog.

Simple focuses on the core drawing tools. Advanced reveals the full toolkit.

Google integration

Run the Apps Script setup once to enable Save to Google, Load from Google, and Cloud Sync.

Google Drive + Sheets Setup

  1. Create a Google Sheet named DrawSplat Saves.
  2. Open Extensions → Apps Script.
  3. Paste the included apps-script/Code.gs code.
  4. Deploy as Web app, run as yourself, accessible to your users.
  5. Copy the Web App URL into Script URL.

The script stores board JSON and PNG exports in Drive and logs saves in the Sheet. It can also store shared room states for cloud collaboration.
