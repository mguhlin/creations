The Method

  
VIBES game plan for this build

  
    
      
  • VVision. Make the Dewey system feel like a game board instead of a wall chart.
    • 
      
  • IInstruct. Provide local shelf-location notes and a starter keyword list (dinosaurs → 500s, etc.).
    • 
      
  • BBuild. Render the 10 segments first; wire up click-to-reveal; add the search-highlight last.
    • 
      
  • EEvaluate. Test on a tablet at the shelf; try odd topics in the search box and fix misroutes.
    • 
      
  • SShip. Project it during orientation, or embed in your Google Site as a self-serve station.
    •
