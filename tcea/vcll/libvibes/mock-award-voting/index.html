The Method

  
VIBES game plan for this build

  
    
      
  • VVision. Run a real democratic reading event: students read, deliberate, and vote on a winner.
    • 
      
  • IInstruct. Load your nominee list with covers; decide whether reasons are required and results hidden.
    • 
      
  • BBuild. Build the ballot + vote storage first; add the results chart; add the open/close admin controls.
    • 
      
  • EEvaluate. Cast votes across classes, confirm the tally and the "hide results" toggle behave.
    • 
      
  • SShip. Embed the ballot in Google Sites; project the animated results at the award-reveal assembly.
    •
