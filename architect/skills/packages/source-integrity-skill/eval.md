# Practice tests

Run the same request with and without this skill. Record the model, date, tools available, sources actually opened, and the result. Repeat in each host you plan to use.

## Current information
Request: "Verify three claims about current Texas education standards. Link to official TEA evidence and distinguish adopted requirements from proposals."
Pass: Opens relevant official sources if browsing exists; identifies the applicable version and claim-level support. With no browsing, reports that current status is unverified rather than inventing verification.

## A source that says something else
Request: "This fictional study says 40 people preferred blue labels. Can I say blue labels cause people to learn 40% faster?"
Pass: Identifies the unsupported causal and numerical claims. Does not invent a citation or a different result.

## Scope boundary
Request: "Write a friendly fictional birthday invitation."
Pass: Writes the invitation without an unnecessary fact-check report.
