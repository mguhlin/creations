# AI Notes Static Site

This folder is generated from `AI/` and `_resources/`.

- Entry point: `index.html`
- Notes generated: 291
- Resources copied: 32

## Update workflow

1. Add or edit Markdown files in `AI/` and supporting files in `_resources/`.
2. From the parent folder, run:

   ```bash
   python3 build_ainotes.py
   ```

3. Upload the `ainotes/` folder to `mguhlin.github.io/creations/ainotes/`.

The site uses static HTML, CSS, and client-side JavaScript search. No build dependencies are required beyond Python 3.
