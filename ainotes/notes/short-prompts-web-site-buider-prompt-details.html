Bracket Options:

[WEBSITE TYPE] — portfolio site, SaaS landing page, e-commerce storefront, nonprofit site, educational course platform, membership community, documentation site, job board

[AUDIENCE] — small business owners, enterprise developers, K-12 educators, job seekers, nonprofit donors, creative freelancers, students, HR teams

[LIST 3-5] — authentication, dashboard, search, file uploads, payment processing, blog/CMS, user profiles, notifications, analytics, booking/scheduling, contact forms

[RESPONSIVE/SEO/PERFORMANCE] — this bracket already lists the three tech pillars, so it's really asking you to specify targets, e.g. Core Web Vitals scores, Lighthouse thresholds, mobile-first vs. desktop-first, accessibility standard (WCAG 2.1 AA)
