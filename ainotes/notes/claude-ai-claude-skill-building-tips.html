  1. Skills are composable. Claude can load multiple Skills at the same time. So your Newsletter Skill can work alongside your Brand Voice Skill and your Content Calendar Skill. They stack like building blocks. One prompt. Multiple Skills firing.
  1. 4 things not to skip:
  • Keep SKILL .md <5k words. Move detailed docs to a references folder. Claude loads only what it needs.
  • Description field = everything. If Claude doesn't know WHEN to use your Skill, it won't. Include exact trigger phrases.
  • Test by asking Claude: "When would you use the [skill name] skill?" It'll quote your description back. Fix what's missing.
  • Start w/ ONE task you do every week. Get it working perfectly. Then expand. Don't try to build 10 Skills on Day 1.
  1. How to build your first Skill (takes 15-30 minutes):
  • Create a folder on your computer. Name it something simple like "my-newsletter-skill"
  • Inside that folder, create one text file called SKILL. md
  • At the top, add the name of your Skill and a description of when Claude should use it
  • Below that, write your instructions in plain English. Your format. Your rules. Your process.
  • Go to Claude > Settings > Capabilities > Skills. Upload the folder. Done.
