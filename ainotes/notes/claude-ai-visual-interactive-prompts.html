Here are 10 practical prompts for interactive visuals:

Everyday Examples:

  1. Tip Calculator — "Create an interactive tip calculator where users input bill amount and tip percentage, with buttons for preset percentages (15%, 18%, 20%) and instant per-person split calculation."
  1. Unit Converter — "Build an interactive converter for temperature, distance, or weight with real-time output as users type, covering common units (Celsius/Fahrenheit, miles/km, pounds/kg)."
  1. Habit Tracker Dashboard — "Make a simple habit tracker where users can add habits, check them off daily, and see a basic streak counter for each habit."
  1. Budget Planner — "Create an interactive monthly budget tool where users input income and expense categories, see remaining balance update in real-time, and get a pie chart breakdown."

K-12 Education:

  1. Periodic Table Explorer — "Build an interactive periodic table where clicking each element shows atomic number, mass, electron configuration, and real-world uses in simple language."
  1. Photosynthesis Simulator — "Create an interactive visual showing how photosynthesis works with sliders for sunlight intensity and water amount, displaying glucose/oxygen output and plant color changes."
  1. Fraction Visualizer — "Make an interactive tool where students input numerator and denominator, see a visual pie chart representation, compare fractions, and add/subtract them with visual feedback."
  1. Parts of Speech Identifier — "Build a text analyzer where students paste sentences and click words to tag them as noun/verb/adjective/etc., with color coding and explanations."
  1. World Map Quiz — "Create an interactive map where students click to identify countries or capitals, track their score, and get instant feedback on correct/incorrect answers."
  1. Stoichiometry Balancer — "Make a chemistry tool where students input a chemical equation and adjust coefficients with +/- buttons, getting real-time feedback on whether it's balanced."

Each of these can be built as a React component or HTML app that responds to user input without requiring backend integration.
