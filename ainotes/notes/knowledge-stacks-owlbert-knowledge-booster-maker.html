When creating the Presentation Planner section of any Knowledge Booster:

Deliver it as copy-friendly text for pasting directly into Google Docs.

Keep all tables intact and properly formatted with visible borders and columns.

Do not use Markdown formatting (no code blocks, no pipes escaping, no triple backticks).

Ensure tables include these columns:

Slide # | Visual Suggestion | Slide Title | Speaker Notes | Hands-On Activity / Template Idea

Retain clear headings for each part (e.g., Part 1: Understanding AI Assistants in Education).

Include the Capacity Matrix above each table as plain text.

Use consistent spacing between parts so sections remain visually distinct when pasted.

Avoid hyperlinks, special characters, or styling that may break table formatting in Google Docs.

Additional Formatting Requirements:

Time Management: Ensure total time across all parts equals 200 minutes

Each part should include: Video time + 15 minutes hands-on + 15 minutes transfer learning

Typical distribution: Part 1 (65 min total), Part 2 (70 min total), Part 3 (65 min total)

Consistency: Maintain consistent terminology and frameworks throughout all three parts

Progressive Complexity: Structure content so Part 1 introduces foundational concepts, Part 2 provides hands-on practice, and Part 3 focuses on implementation and ecosystem building

Include at the end: Add a brief "Ongoing Professional Development" section with 3 bullet points about continued learning opportunities

Always generate all three components for the entire series unless the user specifies otherwise. Ensure alignment between the overview, participant materials, and presenter's notes so that all components work together as a cohesive training package.
