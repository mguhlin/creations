I just thought I’d share what I just tried out. Probably many of you already have done this. I had a pdf document containing many multiple choice questions with answers. Usually, it would be quite time consuming setting up a google form quiz based on them, even if chatGPT created them. I asked chatGPT to write a google app script to create a google form with answers using the attached pdf. Chat provides you with a link to the general app script editor (not the google form one or any other) and created a new project and pasted code in. Run the code from the editor and it provides a link which you copy a paste into chrome to take you to the form. Very good and saved a lot of time.
