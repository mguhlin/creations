Recommended Team Setup

For several people editing at once, use a shared Google Sheet or a small cloud database as the source of truth. A shared Google Drive folder lets everyone open the same files without sharing anyone's whole computer.

  1. Create one shared Drive folder named Work Orders.
  2. Share only that folder with staff emails.
  3. Keep backups exported from this app in that folder.
  4. When ready, move the CSV into Google Sheets for live multi-user editing.
